# Base Motion Tokens

Base motion tokens provide the foundational timing and easing values for animations and transitions.
These tokens are used to build our system duration and easing tokens, which provide semantic naming
and usage guidance. We recommend using system motion tokens for all animations and transitions,
rather than using base tokens directly.

> **Note:** For motion usage guidelines, including information on how to choose appropriate duration
> and easing values, see the
> [Canvas Motion Documentation](https://design.workday.com/design-system/tokens/motion).

## Duration

Durations range from 0ms to 1000ms in 50ms steps.

## Easing

Easing tokens define timing functions (cubic-bezier curves) for animations and transitions. There
are two categories:

- **Quick (A)** - For shorter, faster interactions
- **Purposeful (B)** - For longer, more meaningful transitions

Each category includes three variants:

- **Standard** - Balanced easing for general use
- **Acceleration** - Starts slowly and speeds up
- **Deceleration** - Starts quickly and slows down
