# System Brand Colors

System brand tokens are **themed variables** that apply [brand tokens](/docs/tokens-brand-colors--docs)
to the UI. They are the tenant-themeable counterparts of the surface, accent, foreground, border,
and focus tokens, so components that use them re-theme when a tenant overrides the brand scales.
They adapt to light and dark mode.

Use system brand tokens in components instead of referencing brand tokens directly. Use the regular
system color tokens for colors that should not change with the tenant, such as status colors.

- [Surface](#surface)
- [Accent](#accent)
- [Foreground](#foreground)
- [Border](#border)
- [Focus](#brand-focus)

## Surface

Container backgrounds for primary, critical, caution, and positive messaging, with a `strong`
variant of each, plus `selected` for selected items.

<BrandSurfaceTokens />

## Accent

Solid accents for primary, critical, caution, and positive indicators, plus `action` for
primary calls to action such as buttons.

<BrandAccentTokens />

## Foreground

Text and icon colors for primary, critical, caution, and positive messaging, with a `strong`
variant of each, plus `selected` for selected items.

<BrandForegroundTokens />

## Border

Borders for focused inputs (`primary`) and for error (`critical`) and warning (`caution`) states.

<BrandBorderTokens />

## Brand Focus

Focus rings for interactive elements. `primary` is the default focus ring, `critical` is for elements
in an error state, and `caution` has an `outer` and an `inner` ring for elements in a warning state.
