# Shadow Colors

Shadow tokens are **themed variables** for the colors used in box shadows. They are built to be
combined with the [depth tokens](/docs/docs-system-tokens-depth--docs), which define the offsets and
blur of each elevation level.

- [Depth levels](#depth-levels)
- [Deprecated](#deprecated)
- [Usage](#usage)

## Depth levels

Each depth level (`1` to `6`) has a `key` color for the main shadow and an `ambient` color for the
softer shadow around it.

<ShadowTokens />

## Deprecated

`color.shadow.base` and `color.shadow.ambient` are deprecated. Use the depth level tokens instead.
