# System Line Height Tokens

Line height tokens are useful for adjusting the line height without overwriting other font styles.

## Usage

```css
// styles.css
p {
  line-height: var(--cnvs-sys-line-height-body-md);
}
```

## Tokens

Line height token names match the type levels, e.g. `body.md`.
