# Border Colors

Border tokens are **themed variables** that create clear delineations between content, such as
containers, dividers, and form inputs. They adapt to light and dark mode. Status borders are not
tenant themeable. For tenant-themeable borders, see
[System Brand colors](/docs/docs-system-tokens-color-system-brand-new--docs).

## Default

Borders for containers and dividers. `color.border.default` is the standard border, `strong` is for
more visible separation, `elevated` is for elevated surfaces, and `transparent` reserves space for a
border without showing it.
