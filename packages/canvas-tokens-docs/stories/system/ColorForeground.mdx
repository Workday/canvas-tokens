# Foreground Colors

Foreground tokens are **themed variables** for text and icons. They adapt to light and dark mode and
are designed to keep enough contrast on the matching [surface](/docs/docs-system-tokens-color-surface-new--docs)
tokens. Status foregrounds are not tenant themeable. For tenant-themeable text and icon colors, see
[System Brand colors](/docs/docs-system-tokens-color-system-brand-new--docs).

## Default

Body text and icons. `color.fg.default` is the standard color, `strong` and `stronger` add emphasis
for labels, headings, and titles, `disabled` is for inactive content, and `inverse` is for use on
dark backgrounds.

<ForegroundDefaultTokens />

## Muted

Secondary text for hints, placeholders, and supporting information. Use `strong` when the default
muted color needs more contrast.

<ForegroundMutedTokens />

High contrast text and icons for use on [contrast surfaces](/docs/docs-system-tokens-color-surface-new--docs#contrast).

## Status

Text and icons for error, warning, and success messages. Use the `strong` variants when the default

## Info
