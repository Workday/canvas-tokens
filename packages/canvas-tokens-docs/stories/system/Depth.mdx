# System Depth Tokens

System depth tokens use box shadows to help users understand the spacial relationship of objects in
our UI.

## Tokens

These tokens use a linear step scale (1-6). As the steps increase, the shadows become larger and
more pronounced. Use more subtle shadows for components closer to the base level, and more
pronounced shadows for components further away.
