# System Motion Tokens

System motion tokens include duration and easing. For motion usage guidelines, including information
on how to choose an appropriate duration and easing value, see the
[Canvas Motion Documentation](https://design.workday.com/design-system/tokens/motion).

## Duration Tokens

System duration tokens provide standardized timing values for animations and transitions. Each token
references a base duration token.

```ts
// styles.ts
import {system} from '@workday/canvas-tokens-web';

const styles = {
  transition: `transform var(${system.motion.duration.medium})`,
};
```

## Easing Tokens

System easing tokens provide standardized cubic-bezier curves for animations and transitions across
our UI.

### Usage

Easing tokens can be consumed as a JavaScript / TypeScript object. Each token value references the
CSS variable from a base token, so you'll need to have those CSS variables imported in your
application as well.

```ts
// styles.ts
import {system} from '@workday/canvas-tokens-web';

const styles = {
  transition: `transform var(${system.motion.duration.medium}) var(${system.motion.easing.quick.standard})`,
};
```

They can also be consumed as CSS variables. In the example below, we're applying the same styles
using CSS variables directly.

{/* prettier-ignore */}
```css
// styles.css
.button {
  transition: transform var(--cnvs-sys-motion-duration-medium) var(--cnvs-sys-motion-easing-quick-standard);
}
```

### Categories

System easing tokens are organized into two categories:

- **Quick** - For shorter, faster interactions (hover states, button presses, etc.)
- **Purposeful** - For longer, more meaningful transitions (modals, panels, page transitions)

Each category includes three timing function variants:

- **Standard** - Balanced easing for general use
- **Acceleration** - Emphasizes the beginning of the animation
- **Deceleration** - Emphasizes the end of the animation
