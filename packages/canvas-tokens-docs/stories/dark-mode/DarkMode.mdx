# Dark Tokens

Dark mode is part of the Sana Canvas theme. The same system tokens, such as `system.color.surface.root`
and `system.color.fg.root`, resolve to different values depending on the color mode, so anything styled
with tokens switches between light and dark without code changes.

## Setup

1. Import the Sana CSS variables for both modes. Light values are in `sana/_variables.css` and dark values
   are in `sana/_variables-dark.css`. All CSS can be added through a single `@workday/canvas-tokens-web/css/index.css` import.
2. Set `data-theme="sana-canvas"` on an element that wraps your layout.
3. Set `data-color-mode` to `light` or `dark` on that element, or on any element inside it.

```html
<div data-theme="sana-canvas" data-color-mode="dark">
  <!-- Your layout -->
</div>
```

To switch modes, change the `data-color-mode` value. Because the attribute can also be set on an element
inside the theme, part of a page, such as a single panel or card, can use dark mode while the rest stays
light.
