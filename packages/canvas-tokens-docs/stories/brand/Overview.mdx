# Brand Tokens

Brand tokens are **themed variables** designed for brand and tenant-level customization. They are
not connected to system tokens, which apply across the whole application. Brand tokens drive
buttons, focus rings, status indicators, and banners.

Each brand color category is a scale that references a [base palette](/docs/tokens-base-color-palette--docs)
color. Tenants can override a whole scale to re-theme the UI. Every scale has the same steps
(`25` to `975`), plus alpha steps (`a25` to `a300`), and each step has a dark mode value.

## Primary

The main brand color. Use it for the most prominent interactive elements, such as primary buttons,
links, selected states, and the default focus ring. Defining the primary scale covers most theming
use cases.

## Action

Action tokens give granular control over action elements, such as the regular, hover, and active
states of a primary button.

Action tokens are available **only in code packages** (JS / TS). They have no CSS variables, which
leaves tenants more control over theming. If you reference an action token and it is not defined,
add a fallback so the UI still shows tenant branding.

> **Note:** Use `brand.action.*` with caution. Defining the brand primary scale covers most theming
> use cases. Define action colors only when you need more granular control over elements such as
> `PrimaryButton`.

| Token | Description |
| --- | --- |
| `brand.action.lightest` | Lightest action color |
| `brand.action.lighter` | Lighter action color, such as for subtle backgrounds |
| `brand.action.light` | Light action color |
| `brand.action.base` | Main action color, such as for the regular state of a primary button |
| `brand.action.dark` | Dark action color, such as for the hover state of a primary button |
| `brand.action.darker` | Darker action color, such as for the active state of a primary button |
| `brand.action.darkest` | Darkest action color |
| `brand.action.accent` | Foreground color for content placed on action elements |
